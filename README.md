## Возможности

- Обучение по порядку: по разделам, внутри по последовательности сбора.
- Все 374 вопроса в каждом основном тесте, по порядку или в случайном порядке.
- Проверка каждого ответа или всей попытки в конце.
- Без ограничения времени. Порядок вопросов и способ проверки настраиваются независимо.
- Один ответ, несколько ответов и порядок действий.
- Разбор результатов, повтор ошибок, сохранение текущей попытки и история завершённых попыток в браузере.

## Размещение

Это статический сайт без сборки и сторонних зависимостей. Загрузите файлы из этой папки в корень сайта. Для GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root) → Save.

Посетителям не нужны аккаунты GitHub или ChatGPT. Доступность домена зависит от сети посетителя.

Прогресс хранится только в localStorage текущего браузера и не передаётся на сервер. Очистка данных браузера удалит прогресс. Ответы входят в открытые файлы сайта: это тренажёр для самоподготовки.
